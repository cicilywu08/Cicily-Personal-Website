# Cicily-Personal-Website

Personal site for Cicily Wu — built with Next.js.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Optional: add `OPENAI_API_KEY` in `.env.local` for the story translation API.

## Deploy

Works on [Vercel](https://vercel.com) or any Node host that supports Next.js (`npm run build` / `npm start`).
